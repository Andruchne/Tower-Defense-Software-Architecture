# Description
This project was created in the context of a study module called "Software Architecture", using the Unity Engine. Goal of this course was to create a Tower Defense game, implementing different systems to seperate responsibilites. As such, design patterns such as observer pattern, event bus, next to singletons were used. The game was to be flexible, reusable, and readable, with enough error tolerance implemented. This wiki will provide a short overview of what functionality was implemented through which manner.

To see more details on the implementations made, either look at the Wiki Documentation page, or read through the code of the scripts directly. Every script also contains a summary of it's purpose.
